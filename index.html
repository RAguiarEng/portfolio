Sistema de Gestão — ERP

Em produção

Sistema de gestão interna desenvolvido para uma empresa em Jaraguá do Sul, Brasil. Projetado para gerenciar o controle de pedidos, cadastro de clientes e fornecedores, e gestão financeira.

Tecnologias utilizadas:

  • Backend: Django (Python)
  • Frontend: HTML, CSS, JavaScript, Bootstrap 5
  • Banco de dados: SQLite (dev) / PostgreSQL (produção)
  • Infraestrutura: Ubuntu VPS, Nginx, Gunicorn, SSL Let's Encrypt
Desenvolvido e implantado no primeiro semestre de 2026.
